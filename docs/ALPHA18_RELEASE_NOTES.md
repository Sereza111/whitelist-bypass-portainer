# v0.5.0-alpha.18

## HTTPS для панели

- `panel.yozik.ru` направлен на VPS `93.189.230.198`.
- Manager больше не публикуется на всех интерфейсах: Stack использует
  `127.0.0.1:9200:8080`.
- Готовый Nginx-конфиг проксирует домен на loopback manager.
- Certbot выпускает и автоматически продлевает сертификат Let's Encrypt.
- Пароль панели, номер телефона WB и одноразовый код больше не требуется
  передавать через публичный HTTP.

## Устойчивый вход WB Stream

- Ожидание страницы WB увеличено до двух минут: защита «Проверяем браузер» на
  VPS может занимать значительно больше прежних 45 секунд.
- Распознавание формы больше не зависит только от одного placeholder.
- Manager повторно ищет кнопку «Войти» и форму номера, пока не истечёт bounded
  timeout.
- При сбое сохраняется только безопасная диагностическая screenshot страницы
  до ввода номера; cookies, номер и код в неё не попадают.
- Панель показывает эту screenshot вместо общей непрозрачной ошибки.

## Развёртывание

1. Redeploy `ghcr.io/sereza111/whitelist-bypass-portainer:v0.5.0-alpha.18`.
2. Установить `docs/nginx-panel.yozik.ru.conf`.
3. Выполнить `certbot --nginx -d panel.yozik.ru`.
4. Открыть `https://panel.yozik.ru` и повторить вход WB.
